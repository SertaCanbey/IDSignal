# IDSignal
Open-source Microsoft Entra Security Analyzer. Local, privacy-first, and fast.
Detect password spray campaigns and weak MFA configurations with zero cloud dependencies.

## Quick Start
`ash
docker-compose up -d
`
Navigate to http://localhost:4317

## Features
- Zero Cloud Dependencies
- Detect Password Spray (Event 50126)
- Find accounts missing MFA
